# Assignment 2 — Factory Method & Abstract Factory

## Author

Sanzhar Zhussupov

## Description

This project demonstrates the implementation of two creational design patterns in Java:

* **Factory Method** — creation of a single product through specialized creators.
* **Abstract Factory** — creation of families of related products through factory objects.

## Technologies

* Java 17
* IntelliJ IDEA

## Project Structure

* `factorymethod/` — Factory Method implementation
* `abstractfactory/` — Abstract Factory implementation

## How to Run

1. Clone the repository.
2. Open the project in IntelliJ IDEA.
3. Run the client (`Main`) class.

## Design Patterns Used

* Factory Method
* Abstract Factory
